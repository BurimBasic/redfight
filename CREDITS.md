# Авторство и сторонние компоненты

«Красный поединок / Red Rivalry» — оригинальный юмористический пиксельный файтинг на Unity.

- Игровая логика, интерфейс, эффекты, анимационная система и оригинальная композиция «Бумага и пар» подготовлены для этого проекта.
- Иллюстрации персонажей, арены и дополнительные кадры созданы с помощью ImageGen.
- Для воспроизведения и сборки используется Unity; права на движок и распространяемые компоненты Unity принадлежат их правообладателям.
- Финальный AY-звук отрендерен с помощью [Ayumi JS](https://github.com/alexanderk23/ayumi-js), порта [Ayumi](https://github.com/true-grue/ayumi). Сторонний код и исходная MIT-лицензия находятся в [Music/AY-Source](Music/AY-Source).
- Названия настоящих книг Ленина приведены для юмористических игровых приёмов. [Источники](docs/BOOK-SOURCES.txt).

Лицензия Ayumi распространяется на соответствующий сторонний компонент. Общая лицензия на повторное использование кода, музыки и графики игры в этом репозитории пока не выбрана.
