# Бумага и пар

Оригинальная тема игры: 152 BPM, около 1:41. Основная мелодия развивается через понижение тональности, контрастный ответ, спокойную середину и возвращение с украшениями.

Финальный звук использует эмуляцию **AY-3-8910**: три физических голоса, общий шум и аппаратная огибающая; частота чипа 1 773 400 Гц, обновление регистров 50 Гц.

| Файл | Назначение |
| --- | --- |
| `../UnityProject/Assets/Resources/Audio/PaperAndSteam.wav` | Финальная запись, звучащая в игре |
| `PaperAndSteam-AY.ym` | Переносимая регистровая запись YM6 |
| `PaperAndSteam-Score.mmp` | Редактируемый нотный эскиз для LMMS; его синтезаторы звучат иначе, чем финальный AY-рендер |
| `PaperAndSteam.mid` | Ноты в MIDI |
| `AY-Source/score.json` | Исходная структура композиции |
| `AY-Source/render-ay.mjs` | Генерация AY-регистров и звука |

Для повторного рендера установите Node.js и выполните из `Music/AY-Source`:

```text
node render-ay.mjs
```

В папке `Music` появятся WAV, YM6 и параметры рендера. Скрипт также обновит WAV в соседнем Unity-проекте, если его папка существует. Дополнительные пакеты не требуются. Лицензия эмулятора: [MIT](AY-Source/LICENSE.txt).
